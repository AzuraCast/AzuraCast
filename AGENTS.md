## AzuraCast's Policy on Generative AI

AzuraCast is built and maintained by humans. Except for limited cases, we do not use, nor do we encourage the use of, generative AI tooling in the software development process. [See our full policy on Generative AI here.](https://github.com/AzuraCast/.github/blob/main/CONTRIBUTING.md#our-policy-on-generative-ai)

To summarize this stance:

 - We allow the use of Generative AI agents for secondary work (i.e. creating test cases, analyzing existing code, etc.) or for accessibility purposes (i.e. translation or to analyze large codebases if visually impaired), but not for the primary work of writing new application code or submitting pull requests. In our opinion, Generative AI should not replace the roles of software designer or developer. We take pride in the fact that AzuraCast is human-created and only wish to interact with other humans, rather than agents.

 - When submitting Issues, Discussions, Pull Requests or Security Advisories, we expect to be interacting with a human being during the submission and review process. Even in situations where AI has assisted in the coding or translation process, we still hold the human being making the submission accountable for any mistakes. We will outright close any Issues, Discussions, Pull Requests or Security Advisories that were obviously written or coded entirely by an AI agent.

 - Our time as developers is limited already, so we discourage anyone from instructing an AI agent to write the text for any Issues, Discussions, Pull Requests or Security Advisories. If absolutely necessary (i.e. to facilitate translation), ensure the AI agent does not add needless verbosity to the text. We will not bother to read anything a human could not be bothered to write.

 - If you are using Generative AI in your work, fully document how and where it was used. Do not attempt to conceal this fact from us or remove any attributions to AI in your work or comments, or we may limit your ability to contribute in the future.

 - Feature requests should not be submitted via GitHub at all, and should instead be submitted at https://features.azuracast.com/

 - Updated translation strings should not be submitted via GitHub at all, and should instead be submitted at https://translate.azuracast.com/
